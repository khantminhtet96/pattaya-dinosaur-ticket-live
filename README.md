# Pattaya Dinosaur Kingdom — Ticket Management

Official project name used throughout the UI: **Pattaya Dinosaur Kingdom**

Features:
- Unlimited ticket types
- Ticket image, name, price and quantity
- + / - quantity
- Add quantity (e.g. 5 + 10 = 15)
- Functional Home / Tickets / Settings / Backup navigation
- Glass + classic office UI
- Mobile-first for iPhone/Samsung and desktop
- Supabase Realtime-ready architecture
- Local fallback when Supabase is not configured

For multi-phone live data, connect this project to a dedicated Supabase production project.
For automatic software updates, connect the Vercel project to the project's GitHub repository so pushes deploy automatically.
